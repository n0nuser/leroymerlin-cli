`leroymerlin` is an unofficial command-line client for leroymerlin.es. It reads the
public storefront and prints JSON, so a store list, a category tree or a stock check
can go straight into a script, a timer or an agent.

leroymerlin.es sits behind bot protection. The cli does not try to log in by itself:
`auth harvest` opens a real Chrome window and reads the session out of it, or
`auth login` imports an export you already have. Stores and categories come from the
public sitemaps and work before either.

## A first look

```bash
leroymerlin store list --query madrid --format pretty
leroymerlin category list --depth 1
leroymerlin auth harvest
leroymerlin doctor
```

Every command prints JSON unless asked otherwise. Errors go to stderr, so a pipe only
sees results.

```bash
leroymerlin store list --format jsonl | jq -r .slug
leroymerlin category list --query cemento --format json
```

## What it will not do

The cli is read-only. It does not add to a cart, place an order, change account
settings or write anything to leroymerlin.es. It has no password login: only an
imported browser session gets past the bot protection.

It is also deliberately slow. Requests are sequential and spaced apart, because this
is a tool for one person checking a shelf, not a crawler.

<Callout type="warn" title="unofficial">
  There is no public API. The cli reads the same pages and sitemaps your browser
  reads, so a site change can break it. When that happens it stops with exit `7` and
  a prefilled issue link instead of returning empty results. See
  [when the site changes](/docs/api-changes).
</Callout>
