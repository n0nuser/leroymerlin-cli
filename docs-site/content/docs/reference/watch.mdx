## `leroymerlin watch`

Track a search or a product and report only what changed

Track a search or a product and report only what changed.

A watch is local. "check" fetches every watch once, compares it with the last
check and prints the differences as events; "run" loops in the foreground.
Watches and their history live in the state database, never on leroymerlin.es.

```bash
leroymerlin watch add search "cemento cola" --max-price 20 --name cola
leroymerlin watch add product 81866477 --name pegoland
leroymerlin watch list
leroymerlin watch check --all
leroymerlin watch check --all --format jsonl | jq -r 'select(.type=="product.price_changed") | .product.url'
leroymerlin watch events cola --since 24h
```

### `leroymerlin watch add`

Create a watch

#### `leroymerlin watch add product`

Watch one product for price and stock changes

```bash
leroymerlin watch add product REF [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--emit-initial` | bool | - | report everything that exists now as events instead of baselining silently |
| `--interval` | duration | `0s` | how often this watch is due (default from config, 5m; floor 30s) |
| `--name` | string | - | watch name (required, used in events and commands) |
| `--notify` | stringSlice | - | sink names from config.toml, repeatable |

#### `leroymerlin watch add search`

Watch a search for new products and price changes

```bash
leroymerlin watch add search [keywords...] [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--brand` | stringSlice | - | brand filter, repeatable (matches the site's Marca filter) |
| `--category` | string | - | browse one category path instead of a text search (see `leroymerlin category list`) |
| `--emit-initial` | bool | - | report everything that exists now as events instead of baselining silently |
| `--in-stock` | bool | - | only products the site can add to the cart |
| `--interval` | duration | `0s` | how often this watch is due (default from config, 5m; floor 30s) |
| `--limit` | int | - | keep at most N products from the page (0: all) |
| `--max-price` | string | - | maximum price in euro |
| `--min-price` | string | - | minimum price in euro |
| `--name` | string | - | watch name (required, used in events and commands) |
| `--notify` | stringSlice | - | sink names from config.toml, repeatable |
| `--page` | int | `1` | result page |
| `--pages` | int | `1` | result pages to diff per check |
| `--sold-by-leroy-merlin` | bool | - | only products the site sells itself |
| `--sort` | string | `relevance` | order: relevance, price-asc, price-desc |

### `leroymerlin watch check`

Fetch each watch once and report what changed

```bash
leroymerlin watch check [NAME] [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--all` | bool | - | every watch of this profile |

### `leroymerlin watch events`

Print stored events

```bash
leroymerlin watch events [NAME] [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--limit` | int | - | at most N events (0: all) |
| `--since` | string | - | only events newer than this duration, e.g. 24h |
