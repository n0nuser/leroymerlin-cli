## `leroymerlin profile`

Several sessions side by side, one per store

A profile is one imported session. Since stock follows the store chosen in
that session, one profile per store lets you compare stores:

  leroymerlin auth login --cookies madrid.json --profile madrid
  leroymerlin auth login --cookies getafe.json --profile getafe
  leroymerlin profile use madrid

### `leroymerlin profile list`

List profiles that have a session

```bash
leroymerlin profile list
```

### `leroymerlin profile remove`

Delete a profile's session

```bash
leroymerlin profile remove NAME [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--yes` | bool | - | do not ask |

### `leroymerlin profile use`

Make NAME the default profile

```bash
leroymerlin profile use NAME
```
