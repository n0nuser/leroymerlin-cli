## `leroymerlin store`

Leroy Merlin stores in Spain

Leroy Merlin stores in Spain.

The list comes from the site's public store sitemap and needs no session.
Stock is always for one store: the one selected in the browser session the
profile was imported from. Use one profile per store to compare stores.

### `leroymerlin store list`

List stores (from the public sitemap, no session needed)

```bash
leroymerlin store list [flags]
```

List every store from the public store sitemap, sorted by name.

```bash
leroymerlin store list --format pretty
leroymerlin store list --query madrid
leroymerlin store list --format jsonl | jq -r .slug
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--compact` | bool | - | only the smaller "Compact" format stores |
| `-q, --query` | string | - | only stores whose name or slug contains this (accents ignored) |
