## `leroymerlin config`

Read and write config.toml

Read and write config.toml. Keys are dotted paths; unknown keys are refused.
Sessions are not in this file: they live 0600 under the sessions directory.

```bash
leroymerlin config path
leroymerlin config set default_profile madrid
leroymerlin config get default_profile
```

### `leroymerlin config get`

Print one key

```bash
leroymerlin config get KEY
```

### `leroymerlin config list`

Print the whole config

```bash
leroymerlin config list
```

### `leroymerlin config path`

Print where config, sessions and state live

```bash
leroymerlin config path
```

### `leroymerlin config set`

Set one key

```bash
leroymerlin config set KEY VALUE
```
