## `leroymerlin sink`

Sinks from config.toml: where watch events are copied

Sinks from config.toml: where watch events are copied.

By default events go to stdout. A watch can also name sinks with --notify; they
receive a copy of every event of that watch. Three types are supported:

  [sinks.topic]
  type = "ntfy"
  url = "https://ntfy.sh"
  topic = "leroymerlin"

  [sinks.hook]
  type = "webhook"
  url = "https://example.invalid/hooks/leroymerlin"

  [sinks.script]
  type = "exec"
  command = ["~/bin/on-leroymerlin-event"]

### `leroymerlin sink list`

List the sinks declared in config.toml

```bash
leroymerlin sink list
```

### `leroymerlin sink test`

Send a test event to one sink

```bash
leroymerlin sink test NAME
```
