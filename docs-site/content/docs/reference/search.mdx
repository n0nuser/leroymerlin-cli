## `leroymerlin search`

Search the catalogue, or browse one category

```bash
leroymerlin search [keywords...] [flags]
```

Search the catalogue, or browse one category.

Filters are the ones the site offers: --brand (its Marca facet), --min-price
and --max-price, --sold-by-leroy-merlin, and --sort. --in-stock keeps only
what the site says it can add to the cart. --category browses a branch of the
tree from the public sitemap, instead of a text search.

Results are server-rendered; the site loads the tail of a page lazily, so a
page reports the total the site gives and the products it embedded.

```bash
leroymerlin search "cemento cola" --format pretty
leroymerlin search "mortero" --brand SIKA --max-price 30 --sort price-asc
leroymerlin search --category construccion/cementos-morteros-y-yesos/cementos --in-stock
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--brand` | stringSlice | - | brand filter, repeatable (matches the site's Marca filter) |
| `--category` | string | - | browse one category path instead of a text search (see `leroymerlin category list`) |
| `--in-stock` | bool | - | only products the site can add to the cart |
| `--limit` | int | - | keep at most N products from the page (0: all) |
| `--max-price` | string | - | maximum price in euro |
| `--min-price` | string | - | minimum price in euro |
| `--page` | int | `1` | result page |
| `--sold-by-leroy-merlin` | bool | - | only products the site sells itself |
| `--sort` | string | `relevance` | order: relevance, price-asc, price-desc |
