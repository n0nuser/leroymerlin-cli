## `leroymerlin category`

The product category tree

### `leroymerlin category list`

List categories (from the public sitemap, no session needed)

```bash
leroymerlin category list [flags]
```

List product categories from the public category sitemap, parents first.
PATH is the part of the category URL after /productos/.

```bash
leroymerlin category list --depth 1 --format pretty
leroymerlin category list --parent construccion --depth 2
leroymerlin category list --query cemento
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--depth` | int | - | levels below --parent (or the top) to include; 0 for all |
| `--parent` | string | - | only categories below this path |
| `-q, --query` | string | - | only categories whose name or path contains this (accents ignored) |
