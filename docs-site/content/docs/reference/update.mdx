## `leroymerlin update`

Update leroymerlin to the latest stable release

```bash
leroymerlin update [flags]
```

Check GitHub for the latest stable release and replace this binary with it,
after verifying the archive against the release's checksums.txt. --check only
reports; --yes skips the prompt. Development builds (go install from a
branch, local builds) are never replaced: reinstall with go install instead.

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--check` | bool | - | only report whether an update exists |
| `--yes` | bool | - | update without asking |
