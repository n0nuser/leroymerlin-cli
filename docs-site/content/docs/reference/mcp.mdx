## `leroymerlin mcp`

Serve the read commands to an agent over MCP (stdio)

```bash
leroymerlin mcp
```

Run a Model Context Protocol server on stdin/stdout. Each tool runs the
command it is named after and returns the same JSON. Everything is read-only.

Tools: store_list, category_list, doctor

```bash
leroymerlin mcp install claude-code
leroymerlin mcp install codex --profile madrid
leroymerlin mcp                 # normally started by the harness
```

### `leroymerlin mcp install`

Register this binary in an agent harness's MCP config (idempotent)

```bash
leroymerlin mcp install claude-code|codex|cursor
```

Add this binary as the leroymerlin MCP server in ~/.claude.json (claude-code), ~/.codex/config.toml (codex) or ~/.cursor/mcp.json (cursor). Other entries are kept; running it twice reports "unchanged".
